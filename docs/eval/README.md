# 카드 LLM 평가 기록 (#59 #61)

오늘의 카드는 서버가 후보 3개와 점수를 정하고, LLM 이 하나를 고르고 두 문장을 쓴다.
LLM 출력은 세 겹으로 막는다: 프롬프트 규칙, 출력 스키마 강제, 서버 검증(`reject_reason`).
이 문서는 그 LLM 이 실제로 얼마나 규칙을 지키는지 잰 기록이다.

## 평가 방법

`scripts/eval_cards.py` 가 상황 30개를 실제 LLM 에 넣는다 (#61 에서 24개, #108 에서 6개 추가: 노을 창+미세먼지 나쁨, 취향이 노을이어도 비, 같은 공원 입구 3개, 환승 노선 라벨, 자동차 도착 후 2개, 도보 전체 우회 상한 근처).

- **서비스 검증**: 서비스와 같은 `reject_reason`. 후보 범위, 입력에 없는 장소·정류장 이름
- **상황별 기대값**: 최근 추천 회피, 비·눈·밤에 노을 이유 금지, 노을 창이면 노을 이유,
  미세먼지 나쁜 날 가장 짧은 길, 1위가 아니면 이유(deviation), 문장 속 숫자는 입력값,
  계절 상태를 지어내지 않기
- 다른 LLM 을 검사관으로 쓰지 않는다. 규칙 검사는 매번 같은 결과를 내서 개선 전후를 비교할 수 있다

```bash
uv run python -m scripts.eval_cards --repeat 2   # 상황당 2회, 결과는 docs/eval/cards.md
```

## 개선 기록 (2026-11-07, `claude-opus-5-5`)

| 회차 | 호출 | 검증 통과 | 기대값 충족 | 1위 아닌 선택 | 발견 → 조치 |
| --- | --- | --- | --- | --- | --- |
| 1 | 24 | 100% | 88% | 25% | 노을 창(일몰 6분 뒤·맑음)인데 공원 선택 → 서버가 계산한 `sunset_window_open` 을 입력에 넣고 규칙 4에 한 줄 추가. 미세먼지 나쁜 날 "공기" 이유 칩은 근거 있는 판단이라 기대값을 "가장 짧은 길"로 수정 |
| 2 | 48 | 100% | 100% | 52% | 상황 3개의 후보가 점수순이 아니었음 (평가 설계 오류) → 점수순으로 고치고 테스트로 고정 |
| 3 | 48 | 100% | 100% | 38% | 문장 13개가 "억새가 한창" 처럼 입력에 없는 계절 상태를 단정 → 기대값 추가 (이 기준으로 73%) |
| 4 | 48 | 98% | 98% | 15% | 규칙 1에 "season_tags 는 계절 풍경일 뿐, 한창·절정이라 단정하지 않는다" 추가 → 상태 단정 13 → 0. 실패 1건은 API 호출 실패(서비스는 템플릿으로 폴백) |
| 5 | — | — | — | — | #108 상황 6개 추가로 세트는 30개. 아직 돌리지 않았다. 아래 수치는 전부 24개 기준이며, `--repeat 2` 로 다시 돌리면 `cards.md` 가 30개 기준으로 바뀐다 |

1위가 아닌 선택이 52% → 15% 로 준 것은 "억새가 한창" 같은 근거 없는 이유로 순위를 뒤집던 경우가 사라졌기 때문이다.
남은 15% 는 최근 추천 회피(강제)와 사용자 태그 선호처럼 입력에 근거가 있는 경우다.

## 모델 비교 (2026-11-08, #71)

같은 프롬프트·같은 상황 24개 × 2회. Opus 는 4회차 결과, Haiku 는 같은 날 새로 돌렸다.
카드당 비용은 실측 평균 토큰 × 문서 단가 (Opus 5.5 $4/$20, Haiku 5.5 $0.10/$0.50 per MTok).

| 지표 | Opus 5.5 (현재) | Haiku 5.5 |
| --- | --- | --- |
| 서비스 검증 통과 | 98% (실패 1 = API 호출 실패) | 96% (실패 2 = 문장 80자 초과로 스키마 위반 → 템플릿 폴백) |
| 기대값 충족 (반말 검사 포함) | 98% | 88% |
| 반말 끝맺음 ("좋다." 등) | 0 / 47 | 4 / 46 |
| 녹지 % 를 문장에 넣음 | 6 / 47 | 35 / 46 |
| 평균 출력 토큰 | 161 | 443 |
| 평균 응답 시간 | 2.8초 | 3.0초 |
| 카드 1장 비용 | 약 $0.010 | 약 $0.0004 (약 25분의 1) |

- Haiku 는 규칙 대부분을 지키지만 말투가 흔들리고("좋다." "30%다."), 숫자를 나열하는 문장이 많다
- 빠르지도 않았다. 출력 토큰이 Opus 의 약 2.8배다
- **결정: 시연은 Opus 5.5 유지.** 카드 1장 약 1센트라 시연 규모에서 비용 부담이 없고 문장 품질이 낫다.
  사용자가 늘면 Haiku 에 말투·길이 규칙을 보강하고 이 평가로 다시 비교한다
